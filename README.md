# 赛博木鱼 · 功德 +1

纯黑背景的网页版电子木鱼。敲一下，功德加一。

## 特性

- **纯黑背景** + 霓虹描边木鱼，单文件、零依赖、可离线运行
- **敲击特效**：冲击波扩散环、火花粒子、上浮尘埃、屏幕闪光、木鱼挤压回弹
- **音效**：Web Audio 实时合成「梆」声，不需要任何音频文件
- **功德 +1 飘字**，每次敲击从敲击点飘出
- **木槌动画**：弹簧物理驱动，真的会挥下来敲在鱼身上（固定 1/60s 步长，60Hz / 120Hz 屏幕手感一致）
- **计数持久化**：存在 `localStorage`，关掉再开还在
- **里程碑**：每敲满 88 次触发金色特效 + 随机禅语
- **移动端适配**：响应式布局、安全区适配（刘海 / 小白条）、禁止双击缩放
- 桌面端支持空格 / 回车敲击

## 本地运行

直接双击 `index.html` 即可，不需要构建步骤。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动发布到 GitHub Pages。
也可以在 Actions 页面手动触发（`workflow_dispatch`）。

## 已知限制

震动反馈依赖 `navigator.vibrate` API，**仅 Android Chrome 支持，iOS Safari 没有实现该 API**
（这是浏览器层面的限制，网页无法绕过）。iOS 上以画面抖动作为兜底反馈。
